Official Investigation-Support Platform

AI-Based Missing Person Identification & Tracking System

A centralized investigation portal combining automated computer vision, deep facial representations (YuNet & SFace), and human-in-the-loop candidate matching to assist law enforcement officers in locating missing individuals.

🛡️ Privacy By Default

Protected Records

Public users cannot browse face embeddings, confidential case records, or precise sighting locations. Permissions are strictly enforced server-side.

⚖️ Human-In-The-Loop

No Autonomous Decisions

AI similarity scores are mathematical ranking signals, not confirmation of identity. Every match must be investigated and recorded by an authorized officer.

🔬 Biometric AI Pipeline

Deep Feature Representation

Uses OpenCV YuNet DNN for face detection and MobileFaceNet SFace for 128-dimensional normalized facial embeddings and cosine similarity ranking.

Six Core System Modules (Professional Training I)

Implemented according to the presentation architecture and PRD requirements.

MODULE 1
Authentication & RBAC

Secure staff login, JWT token issuance, role-based endpoint protection (Investigator, Admin, Public).

MODULE 2
Case Registration

Case profile enrollment with authorized reference photos and automated single-face validation checks.

MODULE 3
Face Processing

YuNet DNN face detection, landmark alignment, and 128-D vector extraction via SFace.

MODULE 4
Sighting Portal

Public sighting submission with photo upload, location coordinates, timestamp, and anonymous receipt.

MODULE 5
AI Matching Engine

Vector similarity search, Top-K ranked candidate retrieval, and calibrated threshold scoring.

MODULE 6
Review & Case Tracking

Side-by-side evidence inspection, mandatory rationale adjudication, case timeline, and geographic map.
